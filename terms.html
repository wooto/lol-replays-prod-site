이용약관

마지막 수정일: 2026년 10월 11일

LoL Replays는 운영자 PC에서 League of Legends 리플레이 영상을 준비하고, Google OAuth로 승인된 YouTube 채널에 업로드하는 Windows 데스크톱 프로그램입니다. 프로그램을 사용하면 아래 안내가 적용됩니다.

1. 계정과 채널 권한

사용자는 소유하거나 관리 권한을 보유한 YouTube 채널만 연결해야 합니다. Google OAuth 승인 화면에서 요청 권한과 사용 목적을 확인한 후 승인할 수 있습니다. 앱은 Google 계정 비밀번호를 수집하지 않습니다. YouTube 권한은 Google 계정의 서드 파티 앱 액세스 설정에서 철회할 수 있습니다.

2. 자동화와 게시 설정

채널별 자동화는 새 연결 시 일시중지 상태로 등록됩니다. 사용자가 자동화를 켜고 채널·언어·경기 조건·업로드 빈도를 설정하면, 프로그램은 해당 조건에 따라 녹화와 업로드를 수행할 수 있습니다. 영상은 비공개로 업로드된 뒤 썸네일을 적용하고 공개를 진행하고 실제 공개 상태를 확인합니다.

사용자는 목적지 채널, 제목·설명, 썸네일, 공개 범위 및 업로드 결과를 확인할 책임이 있습니다. YouTube가 공개 범위 변경을 적용하지 않거나 API quota·연결 상태·녹화 환경에 문제가 있으면 게시가 지연되거나 완료되지 않을 수 있습니다.

3. 콘텐츠와 외부 서비스

사용자는 업로드할 영상, 이미지, 제목, 설명 및 기타 자료를 사용할 권리와 필요한 허가를 확보해야 합니다. 이 앱을 사용하면 YouTube 이용약관이 적용됩니다. YouTube에 올라간 콘텐츠는 YouTube의 이용약관과 정책을 따릅니다. YouTube Data API Services 사용은 YouTube API Services Developer Policies와 YouTube API Services Terms of Service를 따릅니다.

프로그램은 Google/YouTube API 외에도 경기 후보 선택 및 로컬 녹화에 Riot API와 League 클라이언트를 이용할 수 있습니다. 각 외부 서비스의 사용에는 해당 서비스의 정책이 적용됩니다.
