경기 리플레이를
채널 영상으로 준비합니다.

LoL Replays는 운영자 PC에서 League of Legends 경기 후보를 선택하고 리플레이 영상을 녹화한 뒤, 운영자가 Google OAuth로 승인한 YouTube 채널에 업로드하는 데스크톱 도구입니다.

YouTube API 사용 안내
Google OAuth 승인 화면의 앱 이름은 lol-replays-prod입니다. 이 애플리케이션은 YouTube Data API Services를 사용해 승인된 채널을 확인하고, 영상과 썸네일을 업로드하며, 영상 공개 범위를 확인·설정합니다.
개인정보처리방침 이용약관

동작 방식

  • 운영자가 Google 계정으로 연결하고 영상 목적지 YouTube 채널을 선택합니다.
  • 채널별 언어, 리그, 경기 조건, 업로드 빈도를 설정합니다. 새 채널은 자동화가 꺼진 상태로 시작합니다.
  • 켜진 채널에 대해 프로그램이 경기 후보를 고르고 운영자 PC에서 리플레이를 녹화합니다.
  • 영상은 비공개로 업로드되고, 썸네일을 적용한 뒤 채널과 빈도 조건을 다시 확인한 뒤 공개를 진행하고 결과를 검증합니다.

애플리케이션은 공개 웹 서비스가 아닙니다. 관리 화면은 운영자의 컴퓨터에서만 열리도록 제한되어 있습니다.

Google 권한과 데이터

Google 로그인 암호를 수집하지 않습니다. 앱은 YouTube 영상 업로드, 승인 채널 조회, 영상 공개 범위 관리를 위해 OAuth 권한을 요청합니다. 토큰과 업로드 이력의 저장 및 삭제 요청 방법은 개인정보처리방침에서 확인할 수 있습니다.

Google의 개인정보처리 방식은 Google 개인정보처리방침을 확인해 주세요.
