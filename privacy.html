LoL Replays는 운영자 PC에서 실행하는 Windows 데스크톱 애플리케이션입니다. 이 방침은 프로그램이 Google OAuth와 YouTube Data API Services를 이용해 처리하는 정보와 삭제 요청 방법을 설명합니다.

문의 및 데이터 삭제 요청: baleen37@gmail.com

1. 처리하는 정보와 이용 목적

  • OAuth 연결 정보: YouTube 채널 연결과 API 호출에 쓰이는 access token, refresh token 및 승인 범위. Google 계정 비밀번호는 앱이 받거나 저장하지 않습니다. 토큰은 Windows DPAPI로 암호화한 파일에 저장됩니다.
  • 채널 정보: 사용자가 승인한 계정에서 조회한 YouTube 채널 ID와 제목. 채널 선택, 채널별 설정과 업로드 목적지 확인에 사용합니다.
  • 영상과 업로드 정보: 운영자 PC의 영상 파일, 제목, 설명, 카테고리, 생성한 썸네일, YouTube 영상 ID, 공개 범위, 재개 가능한 업로드 세션 URL, 상태·오류, 파일 크기와 지문, 썸네일 경로와 상태. 업로드, 중단 복구, 목적지·공개 범위 확인에 사용합니다.
  • 채널 설정과 작업 기록: 언어, 리그, 경기 기준, 업로드 빈도, 후보 경기, 처리 단계와 게시 이력. 자동화 동작을 관리하고 같은 경기의 중복 작업을 막는 데 사용합니다.
  • 선택적 공개 차트 정보: 운영자가 별도 API 키를 설정한 경우, 지역별 인기 게임 영상의 공개 제목·조회수·게시일을 읽어 메모리에서 경기 후보의 관심 신호를 만들 수 있습니다. 확인한 코드에서는 이 차트 응답이나 계산된 점수를 저장된 후보 기록에 넣지 않습니다. 이 기능은 YouTube Analytics 또는 Reporting API를 호출하지 않습니다.
  • 게임 경기 정보: 경기 후보 선정과 로컬 녹화를 위해 Riot API와 League 클라이언트가 제공하는 경기·선수 정보를 별도로 사용합니다.

2. 저장 위치와 정보 제공

이 공개 안내 사이트는 로그인, 분석 스크립트 또는 자체 쿠키를 사용하지 않습니다. 정적 페이지 호스팅 과정에서 GitHub가 처리하는 정보는 GitHub 개인정보처리방침을 참고해 주세요.

OAuth 토큰 파일은 Windows DPAPI로 암호화하며 승인에 사용한 Windows 사용자 계정으로 보호됩니다. 채널 설정, token 파일 경로, YouTube 업로드 세션·영상 ID·처리 이력은 설치 시 운영자가 지정한 PostgreSQL 데이터베이스에 저장됩니다. 영상과 썸네일은 설치 시 지정한 파일 경로에 저장됩니다. 데이터베이스의 실제 호스트와 백업은 설치별로 다를 수 있습니다.

앱은 OAuth와 YouTube API 기능을 수행하기 위해 필요한 정보를 Google/YouTube에 전송합니다. 업로드한 영상과 메타데이터는 선택한 YouTube 채널에 게시되고 YouTube가 호스팅합니다. 관리 화면은 운영자 PC의 loopback 주소에서만 열립니다.

3. 보유 기간

현재 프로그램은 OAuth 토큰 파일, 채널 설정, YouTube 업로드 기록, 녹화물 또는 썸네일에 공통 자동 만료 기간을 설정하지 않습니다. 실제 보유 기간은 운영자가 지정한 데이터베이스와 파일 저장소를 관리하는 방식에 따라 달라집니다. 기록과 파일은 운영자가 직접 정리할 때까지 남을 수 있습니다.

4. 연결 해제와 삭제 요청

현재 앱에는 Google 권한 철회, 연결 해제 또는 로컬 데이터 삭제를 위한 자체 기능이 없습니다. Google 계정의 서드 파티 앱 액세스 설정에서 LoL Replays 권한을 철회할 수 있습니다. Google에서 권한을 철회해도 운영자 PC의 토큰 파일과 데이터베이스·파일 기록은 자동 삭제되지 않습니다.

운영자가 보유한 데이터의 삭제를 요청하려면 baleen37@gmail.com으로 연락해 주세요. 운영자는 요청 내용과 채널을 확인한 뒤 접근 가능한 로컬 데이터의 위치와 수동 삭제 가능 범위를 검토합니다. 앱의 로컬 기록을 삭제해도 YouTube에 게시된 영상은 삭제되지 않습니다. 영상 자체는 YouTube Studio에서 별도로 관리해야 합니다.
